# Chrome Web Store Listing

Use this copy when publishing or updating the Chrome Web Store listing. The summary comes from `manifest.json`; the description belongs in the Chrome Web Store dashboard.

## Summary

Work faster in Vantage with a clearer timesheet, smarter entry tools, and helpful error checks.

## Description

ad-vantage helps State of Utah employees spend less time navigating the Vantage timesheet and more time completing it accurately. It improves the wide, data-heavy grids in Vantage without changing the underlying timesheet workflow.

Keep key columns pinned while you move across wide timesheets, hide columns you do not need, and hide the Scheduled Hours summary row when it is not relevant. Fetch task lookup data from ServiceNow to show matching descriptions and get type-ahead suggestions while entering Daily Activity codes. Your synced lookup data stays in your current Chrome profile.

Use Ctrl+Shift+. on Windows or Linux, or Command+Shift+. on macOS, to add a Daily Activity record from the keyboard. The new row is brought into view and its Daily Activity field receives focus. You can change the shortcut in Chrome's extension shortcut settings.

The extension also selects the largest available page size for grids with more than 20 rows, provides one-click access to Update Timesheet on the Daily Activity tab, and flags time entries that are not on a quarter-hour increment or have missing Event values. It works with Vantage at vantage.utah.gov and vantage.access.utah.gov.
